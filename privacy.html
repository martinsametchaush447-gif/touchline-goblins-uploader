Privacy Policy: Touchline Goblins Uploader

Last updated: 24 October 2026

Touchline Goblins Uploader is a private tool used only by the owner of the YouTube channel Touchline Goblins to manage that channel's own videos.

What it accesses

With the owner's permission (Google OAuth), it uses the YouTube Data API to upload the owner's videos, read their upload and processing status, list the channel's own uploads, and set a video's privacy status or scheduled publish time. It requests the scopes youtube.upload and youtube.

What it stores

The OAuth token is stored only on the owner's own computer. No YouTube data is sold, shared, or sent to any third party, and no data about other people is collected.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool also follows the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
